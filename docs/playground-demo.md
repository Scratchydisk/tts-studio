# Playground demo

A short walkthrough of generating speech in the Playground tab using the Qwen3-TTS-1.7B model.

<video src="../demo/playground_demo.webm" controls width="100%"></video>

## What this demonstrates

1. **Select a model** — Choose Qwen3-TTS-1.7B from the model dropdown. The info panel shows VRAM requirements, available voices, and supported languages.
2. **Pick a voice** — Select the Eric preset from the 9 available voices.
3. **Generate speech** — Click Generate with the sample text. The status bar shows progress while the model loads and synthesises audio.
4. **Review the result** — The audio player appears with the generated waveform and timing statistics.

## How the narration was made

This is a metademo — the video's narration was generated by TTS Studio itself.

The first step is writing an SRT subtitle file. Each entry has an index, a time range matching when that step appears on screen, and the narration text. Here's the full file used for this demo ([`demo/demo_captions.srt`](../demo/demo_captions.srt)):

```srt
1
00:00:00,500 --> 00:00:03,500
Welcome to the TTS Studio Playground.

2
00:00:04,000 --> 00:00:07,000
First, select the Qwen 3 TTS model from the model dropdown.

3
00:00:08,000 --> 00:00:11,000
The info panel shows the model's VRAM usage and available voices.

4
00:00:12,000 --> 00:00:14,000
Next, choose the Eric voice preset.

5
00:00:15,000 --> 00:00:17,000
Eric is now selected.

6
00:00:18,000 --> 00:00:21,000
The sample text is already filled in and ready to go.

7
00:00:22,000 --> 00:00:27,000
Click Generate to synthesise the speech. The model loads and generates the audio.

8
00:00:28,000 --> 00:00:32,000
And there it is. The generated audio is ready to play.
```

The caption-to-speech pipeline reads each SRT entry, generates speech for it using the chosen model and voice, then renders a new video with the narration mixed in. Where the spoken audio is longer than the on-screen time, the pipeline freezes the frame to fit.

```python
from tts_tests.api import caption_video

result = caption_video(
    video_path="demo/raw_demo.mp4",
    srt_path="demo/demo_captions.srt",
    model_id="qwen3-tts-1.7b",
    voice="Eric",
    output_path="demo/playground_demo.webm",
    output_format="webm",
)
```

See [Caption-to-speech](../README.md#caption-to-speech) for more on the pipeline.
